# Installing the Factorio 2.1 port

The mod name stays `VoidChestByYunli`, so existing `void-chest` entities remain.

1. Download `VoidChestByYunli_2.7.4.zip` from the GitHub release.
2. Put that zip in the Factorio mods folder. Do not unzip it.
   - Windows: `%AppData%\Factorio\mods`
3. In Factorio 2.1, enable **Void Chest + By Yunli**.
4. Leave the older 2.7.3 zip in place if you still have it. Factorio 2.1 uses 2.7.4.
5. Do not enable `VoidChestPlus` at the same time. It defines the same entity name.

Do not upload this zip onto the original mod portal page. That page belongs to `_Yunli_`. This repository is the place to share the port.
